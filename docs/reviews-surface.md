# Review surface contract

## THESIS
Review payment exceptions where staff manage orders, without interrupting every page.

## OWN-WORLD
Inherit WordPress and WooCommerce tables, typography, buttons, navigation and metaboxes.

## STORY
Orders links to a filtered review queue. Open the order for attempt evidence, compare it in AdminTool, then acknowledge explicitly.

## FIRST VIEWPORT
A native page title, compact recovery health, category counts, search and actionable rows. No dashboard cards or global warning wall.

## FORM
User-pinned native layout. Routine cases support selection; consequential cases remain individual. A saved acknowledgement removes its row in place; errors retain evidence and focus. The order panel exposes the latest reference and earlier attempts.

## FINISH
unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
